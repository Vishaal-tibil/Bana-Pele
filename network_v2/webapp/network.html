BAP -- Beckn Application Platform. Acts on the consumer's behalf. The one node the webapps talk to.
Facilitator (Registry + Gateway) -- never transacts, only helps discovery happen.
Independent node -- runs its own real process. SmartStart, Grow, Thabo A/B/C today.
Platform-mediated -- published and answered by the shared My Journey Adapter instead of its own process. Imbe today -- see its catalog card below for why.

Infrastructure

Registry, Gateway and BAP are the three fixed, always-exactly-one nodes. The BPP layer is represented here too, as two live summary cards -- the individual providers and their catalogs still get their own richer section below ("Providers & catalogs") since there can be any number of them.

Providers & catalogs

Independent providers each run their own process; Platform-mediated ones share the My Journey Adapter's -- the badge on each card says which. Every catalog is still read straight from that provider's own /catalog endpoint (with ?provider_id= so the adapter knows which of its mediated providers you're asking about) -- not proxied, not cached elsewhere.
